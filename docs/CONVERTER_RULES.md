# SQL Converter rules

Rules run on code only: text inside `'strings'` and comments is never changed. Simple `[name]` / `"NAME"` quotes are removed. Procedural code (procedures, functions, triggers, variables, error handling) is marked and, if AI is on, finished by the AI using the rule-based draft as a starting point.

## SQL Server (T-SQL) → Oracle

| T-SQL | Oracle |
|---|---|
| `ISNULL(a, b)` | `NVL(a, b)` |
| `LEN(a)` | `LENGTH(a)` |
| `SUBSTRING(a, s, n)` | `SUBSTR(a, s, n)` |
| `CHARINDEX(x, a [, s])` | `INSTR(a, x [, s])` |
| `GETDATE()` / `SYSDATETIME()` / `GETUTCDATE()` | `SYSDATE` / `SYSTIMESTAMP` / `SYS_EXTRACT_UTC(SYSTIMESTAMP)` |
| `NEWID()` | `SYS_GUID()` |
| `IIF(c, a, b)` | `CASE WHEN c THEN a ELSE b END` |
| `YEAR(d)` / `MONTH(d)` / `DAY(d)` | `EXTRACT(YEAR FROM d)` … |
| `DATEADD(day/month/year/week/hour/minute/second, n, d)` | date arithmetic / `ADD_MONTHS` |
| `DATEDIFF(day/month/year/hour/minute/second, a, b)` | `TRUNC(b) - TRUNC(a)` / `MONTHS_BETWEEN` / `ROUND((b - a) * …)` |
| `CONVERT(varchar, x)` / `CONVERT(date, x)` / `CONVERT(type, x)` | `TO_CHAR(x)` / `TRUNC(CAST(x AS DATE))` / `CAST(x AS type)` |
| `SELECT TOP n [PERCENT] [WITH TIES] …` | `… FETCH FIRST n [PERCENT] ROWS ONLY / WITH TIES` |
| `'a' + b` (next to a string literal) | `'a' \|\| b` |
| `@param` (plain queries) | `:param` |
| `SELECT expr` (no FROM) | `SELECT expr FROM DUAL` |
| `WITH (NOLOCK)`, `SET NOCOUNT ON`, `dbo.`, `BEGIN TRAN` | removed |
| `COMMIT TRAN` / `ROLLBACK TRAN` | `COMMIT` / `ROLLBACK` |
| `@@ROWCOUNT` | `SQL%ROWCOUNT` |
| `PRINT x` | `DBMS_OUTPUT.PUT_LINE(x)` |
| `GO` | `/` |
| `CREATE [OR ALTER] PROC/FUNCTION/VIEW/TRIGGER` | `CREATE OR REPLACE …` |
| `INT` / `BIGINT` / `SMALLINT` / `TINYINT` / `BIT` | `NUMBER(10)` / `NUMBER(19)` / `NUMBER(5)` / `NUMBER(3)` / `NUMBER(1)` |
| `DECIMAL(p,s)` / `NUMERIC(p,s)` / `MONEY` / `SMALLMONEY` | `NUMBER(p,s)` / `NUMBER(19,4)` / `NUMBER(10,4)` |
| `VARCHAR(n)` / `NVARCHAR(n)` / `VARCHAR(MAX)` / `NVARCHAR(MAX)` / `NTEXT` / `SYSNAME` | `VARCHAR2(n)` / `NVARCHAR2(n)` / `CLOB` / `NCLOB` / `NCLOB` / `NVARCHAR2(128)` |
| `VARBINARY(n)` / `VARBINARY(MAX)` / `UNIQUEIDENTIFIER` | `RAW(n)` / `BLOB` / `RAW(16)` |
| `DATETIME` / `DATETIME2(n)` / `SMALLDATETIME` / `DATETIMEOFFSET` | `TIMESTAMP` / … / `TIMESTAMP WITH TIME ZONE` |
| `FLOAT` / `REAL` | `BINARY_DOUBLE` / `BINARY_FLOAT` |
| `IDENTITY(s, i)` | `GENERATED BY DEFAULT AS IDENTITY (START WITH s INCREMENT BY i)` |

Warnings: temp tables `#t`, `SCOPE_IDENTITY()`, `NVL(x, '')` (Oracle treats `''` as NULL), unconverted DATEADD/DATEDIFF parts, CONVERT styles, possible column + column string joins.

## Oracle → SQL Server (T-SQL)

| Oracle | T-SQL |
|---|---|
| `NVL(a, b)` / `NVL2(a, b, c)` | `ISNULL(a, b)` / `CASE WHEN a IS NOT NULL THEN b ELSE c END` |
| `LENGTH(a)` | `LEN(a)` |
| `SUBSTR(a, s [, n])` | `SUBSTRING(a, s, n \| LEN(a))` |
| `INSTR(a, x [, s])` | `CHARINDEX(x, a [, s])` |
| `SYSDATE` / `SYSTIMESTAMP` / `SYS_GUID()` | `GETDATE()` / `SYSDATETIME()` / `NEWID()` |
| `ADD_MONTHS(d, n)` / `MONTHS_BETWEEN(a, b)` | `DATEADD(month, n, d)` / `DATEDIFF(month, b, a)` |
| `TO_CHAR(x)` / `TO_CHAR(x, fmt)` | `CAST(x AS NVARCHAR(4000))` / `FORMAT(x, fmt)` |
| `TO_DATE(s [, fmt])` / `TO_NUMBER(x)` / `TRUNC(d)` | `CONVERT(DATETIME2, s)` / `CAST(x AS DECIMAL(38,10))` / `CAST(d AS DATE)` |
| `EXTRACT(part FROM d)` | `DATEPART(part, d)` |
| `DECODE(e, s1, r1, …, default)` | `CASE e WHEN s1 THEN r1 … ELSE default END` |
| `seq.NEXTVAL` | `NEXT VALUE FOR seq` |
| `DATE '…'` / `TIMESTAMP '…'` | `CAST('…' AS DATE)` / `CAST('…' AS DATETIME2)` |
| `a \|\| b` | `a + b` |
| `… FETCH FIRST/NEXT n ROWS ONLY` | `SELECT TOP (n) …` (kept as-is with `OFFSET`) |
| `FROM DUAL` | removed |
| `:bind` (plain queries) | `@bind` |
| `SQL%ROWCOUNT` / `DBMS_OUTPUT.PUT_LINE(x);` | `@@ROWCOUNT` / `PRINT x;` |
| `/` | `GO` |
| `CREATE OR REPLACE PROCEDURE/FUNCTION/VIEW/TRIGGER` | `CREATE OR ALTER …` |
| `NUMBER(1/3/5/10/19)` / `NUMBER(p,s)` / `NUMBER` | `BIT` / `TINYINT` / `SMALLINT` / `INT` / `BIGINT` / `DECIMAL(p,s)` / `DECIMAL(38,10)` |
| `VARCHAR2(n [CHAR])` / `NVARCHAR2(n)` / `CLOB` / `NCLOB` / `BLOB` | `VARCHAR(n)` / `NVARCHAR(n)` / `VARCHAR(MAX)` / `NVARCHAR(MAX)` / `VARBINARY(MAX)` |
| `RAW(16)` / `RAW(n)` | `UNIQUEIDENTIFIER` / `VARBINARY(n)` |
| `TIMESTAMP(n)` / `TIMESTAMP WITH TIME ZONE` | `DATETIME2` / `DATETIMEOFFSET` |
| `BINARY_DOUBLE` / `BINARY_FLOAT` / `PLS_INTEGER` / `BOOLEAN` | `FLOAT` / `REAL` / `INT` / `BIT` |
| `GENERATED … AS IDENTITY (START WITH s INCREMENT BY i)` | `IDENTITY(s, i)` |

Warnings: `||` vs `+` NULL behaviour, format masks, `MONTHS_BETWEEN` fractions, `TRUNC` on numbers, `INSTR` occurrence argument, plain `NUMBER`, `DATE` includes time, `ROWNUM`, `CONNECT BY`, `(+)` joins.

## Confidence

| Level | When |
|---|---|
| High | Plain SQL, every construct handled by rules, no warnings |
| Medium | Plain SQL with warnings, or AI-reported medium |
| Low | Procedural code converted by rules only (AI off or failed) |
